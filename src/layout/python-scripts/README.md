# SubShopApp
Sub Shop App

Files\:  
csv_to_pdf.py \- takes the data in orders.csv and produces a pdf (orders.pdf)  
settings.json \- contains setttings for how the pdf file is to be generated (currently based on a 6 label page from Avery)  
email.py \- sends orders.csv via email  

For those who are not familiar with Python, the env directory contains information for a Python vitrual environment.
