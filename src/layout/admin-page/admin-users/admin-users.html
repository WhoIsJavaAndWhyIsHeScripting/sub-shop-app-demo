Manage Users

If a student ordered a sandwich and did not come to the sub shop to pay for it, type in their full name to add them to the no-access list. Students on the no-access list will not be able to order online, but they will still be able to buy subs in person.

Click "Save Changes" when you are done to save your changes to the no-access list.

No-access list

In the case of a mistake, you can click on the "X" next to a student's name to remove them from the no-access list.
